# iSVN

[English](#english) · [繁體中文](#繁體中文)

---

## English

iSVN is version management for IC design flows. It organises design data as
`<phase>/<block>/<stage>/<version>` on top of Subversion, records which version
each new version was derived from, and stores identical file content once in a
shared, content-addressed cache pool.

It provides:

- `isvn`, a command-line tool (every command can produce JSON with `--json`);
- `isvn-gui`, an optional Qt Quick desktop application that drives the same
  command-line tool.

### Downloads

Each release on the [releases page](https://github.com/LouisLucasLiu/isvn-release/releases)
provides:

| File | Contents |
| --- | --- |
| `isvn-<version>-<commit>-linux-x86_64.tar.gz` | Portable package: `isvn`, `isvn-gui` and the Subversion tools it uses (`svn`, `svnadmin`, `svnmucc`) with their libraries. Qt is **not** included. |
| `isvn-<version>-<commit>-third-party-sources.tar.gz` | Source RPMs of the bundled Subversion components that are licensed under the GNU GPL or LGPL. |
| `SHA256SUMS` | SHA-256 checksums of the release files. |
| Source code (zip / tar.gz) | Generated by GitHub from the release tag. |

Verify a download before installing it:

```sh
sha256sum -c SHA256SUMS --ignore-missing
```

### Requirements

- Linux x86_64 with glibc 2.34 or newer. The command-line tool is tested on
  Rocky Linux 9 and Ubuntu 24.04, the GUI on Ubuntu 24.04.
- For the GUI only: Qt 6.7.3 for Desktop gcc_64, installed by you (for example
  with the Qt online installer), plus the X11/xcb system libraries Qt needs.
  The package checks these and names any missing system package.
- No root access is needed.

### Install the Portable package

```sh
tar -xzf isvn-<version>-<commit>-linux-x86_64.tar.gz
cd isvn-<version>-<commit>-linux-x86_64
./install.sh --qt-dir /path/to/Qt/6.7.3/gcc_64 --yes
```

The package is installed in `~/.local/opt/isvn/<version>` (use `--prefix` to
choose another directory), and `~/.local/opt/isvn/current` points to it.
The installer requires the Qt root, also for command-line use.

```sh
~/.local/opt/isvn/current/isvn-preflight     # checks the machine
~/.local/opt/isvn/current/isvn version
```

Always start the tools through `isvn` and `isvn-gui` in the installation
directory; they put the bundled Subversion tools first on `PATH`.

### Build from source

Requirements: CMake 3.16 or newer, a C++17 compiler (GCC 11 or newer), the
SQLite 3 development files (`libsqlite3-dev` on Ubuntu, `sqlite-devel` on
Rocky Linux), and the Subversion command-line tools at run time. Qt 6.7.3 is
needed only for the GUI.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
      -DISVN_BUILD_GUI=ON -DCMAKE_PREFIX_PATH=/path/to/Qt/6.7.3/gcc_64 \
      -DISVN_APP_VERSION=<version> -DISVN_SOURCE_COMMIT=<commit>
cmake --build build
ctest --test-dir build --output-on-failure
cmake --install build --prefix <install dir>
```

Leave out `-DISVN_BUILD_GUI=ON` and `CMAKE_PREFIX_PATH` to build only the
command-line tool. The GUI tests need `QT_QPA_PLATFORM=offscreen` or a display.

### Getting started

```sh
svnadmin create /data/svn/myproject
isvn admin init --project-dir /data/isvn/myproject --repo file:///data/svn/myproject \
                --pool /data/isvn/myproject-pool --group <project group>
isvn member init --project-dir /data/isvn/myproject --workspace ~/work/myproject
cd ~/work/myproject
isvn create rtl/cpu/RTL/v1 --parent ROOT
```

`isvn` with no arguments lists all commands.

## 繁體中文

iSVN 是給 IC 設計流程使用的版本管理工具。它在 Subversion 之上以
`<phase>/<block>/<stage>/<version>` 組織設計資料，記錄每個新版本是由哪一個版本衍生，
並把內容相同的檔案只存一份在共用的快取池（以內容雜湊定址）。

內容：

- `isvn`：命令列工具（每個指令都可以加 `--json` 輸出 JSON）；
- `isvn-gui`：選用的 Qt Quick 桌面程式，透過同一個命令列工具運作。

### 下載

[Releases 頁面](https://github.com/LouisLucasLiu/isvn-release/releases)的每個版本提供：

| 檔案 | 內容 |
| --- | --- |
| `isvn-<version>-<commit>-linux-x86_64.tar.gz` | Portable 套件：`isvn`、`isvn-gui`，以及它使用的 Subversion 工具（`svn`、`svnadmin`、`svnmucc`）與其函式庫。**不含** Qt。 |
| `isvn-<version>-<commit>-third-party-sources.tar.gz` | 隨附的 Subversion 元件中，以 GNU GPL 或 LGPL 授權者的 source RPM。 |
| `SHA256SUMS` | 發行檔案的 SHA-256。 |
| Source code（zip／tar.gz） | GitHub 依 release tag 產生。 |

安裝前先核對下載的檔案：

```sh
sha256sum -c SHA256SUMS --ignore-missing
```

### 系統需求

- Linux x86_64，glibc 2.34 以上。命令列工具已在 Rocky Linux 9 與 Ubuntu 24.04 測試，GUI 已在 Ubuntu 24.04 測試。
- 只有 GUI 需要：自行安裝的 Qt 6.7.3 Desktop gcc_64（例如用 Qt online installer），以及 Qt
  所需的 X11／xcb 系統函式庫。套件會檢查並指出缺少的系統套件。
- 不需要 root 權限。

### 安裝 Portable 套件

```sh
tar -xzf isvn-<version>-<commit>-linux-x86_64.tar.gz
cd isvn-<version>-<commit>-linux-x86_64
./install.sh --qt-dir /path/to/Qt/6.7.3/gcc_64 --yes
```

套件安裝在 `~/.local/opt/isvn/<version>`（可用 `--prefix` 指定其他目錄），
`~/.local/opt/isvn/current` 指向它。安裝程式一定需要 Qt 根目錄，只用命令列工具時也一樣。

```sh
~/.local/opt/isvn/current/isvn-preflight     # 檢查這台機器
~/.local/opt/isvn/current/isvn version
```

請一律從安裝目錄的 `isvn`、`isvn-gui` 啟動；它們會把隨附的 Subversion 工具放在 `PATH` 最前面。

### 從原始碼建置

需求：CMake 3.16 以上、C++17 編譯器（GCC 11 以上）、SQLite 3 開發檔（Ubuntu 為
`libsqlite3-dev`，Rocky Linux 為 `sqlite-devel`），執行時需要 Subversion 命令列工具。
只有 GUI 需要 Qt 6.7.3。

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
      -DISVN_BUILD_GUI=ON -DCMAKE_PREFIX_PATH=/path/to/Qt/6.7.3/gcc_64 \
      -DISVN_APP_VERSION=<version> -DISVN_SOURCE_COMMIT=<commit>
cmake --build build
ctest --test-dir build --output-on-failure
cmake --install build --prefix <安裝目錄>
```

只建置命令列工具時，省略 `-DISVN_BUILD_GUI=ON` 與 `CMAKE_PREFIX_PATH`。GUI 測試需要
`QT_QPA_PLATFORM=offscreen` 或可用的顯示器。

### 開始使用

```sh
svnadmin create /data/svn/myproject
isvn admin init --project-dir /data/isvn/myproject --repo file:///data/svn/myproject \
                --pool /data/isvn/myproject-pool --group <專案群組>
isvn member init --project-dir /data/isvn/myproject --workspace ~/work/myproject
cd ~/work/myproject
isvn create rtl/cpu/RTL/v1 --parent ROOT
```

不帶參數執行 `isvn` 會列出所有指令。
